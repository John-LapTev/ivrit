# ivrit

Офлайн-приложение для изучения иврита с нуля. Интерфейс на русском, данные хранятся только
в браузере, интернет не нужен.

**Открыть:** https://john-laptev.github.io/ivrit/

Алефбет с таблицей чтения «буква + огласовка», словарь бытового иврита с огласовками
и русской транскрипцией, программа занятий на месяц, уроки грамматики, разговорные сценки,
интервальные повторения (SM-2) и озвучка.

Чистые HTML, CSS и JavaScript без сборщиков и зависимостей. Шрифт для иврита —
Noto Sans Hebrew (SIL Open Font License).
